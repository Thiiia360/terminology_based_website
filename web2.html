Web 2.0

Web 2.0 refers to the second generation of the World Wide Web, characterized by user-generated content, social media, and interactive web applications.

Characteristics of Web 2.0

  • User-generated content (blogs, wikis, social media)
  • Rich internet applications (RIAs)
  • Interactive and dynamic web pages
  • Improved multimedia support (video streaming, audio)
  • Enhanced user experience and engagement
  • Collaborative platforms and communities

🔧 Technologies of Web 2.0

  • HTML 4.01/5.0
  • CSS 2.0/3.0
  • JavaScript frameworks (jQuery, React, Angular)
  • AJAX for asynchronous data loading
  • RESTful APIs for web services

Web 2.0 was about writing, not just reading. Users could create and share content, comment on posts, and interact with each other in real-time.
