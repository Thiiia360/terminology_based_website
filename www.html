World Wide Web (WWW)

The World Wide Web (WWW) is an information system where documents and other web resources are identified by URLs, interlinked by hypertext, and accessible via the Internet.

History & Origins

Invented by Sir Tim Berners-Lee in 1989 at CERN, the WWW was originally conceived as a way for scientists to share research papers automatically. The first web browser (WorldWideWeb) and web server were released in 1991.

Key Components

  • Web Browsers - Client software to request and render web pages (Chrome, Firefox, Safari)
  • Web Servers - Host websites and serve content to browsers
  • HTTP/HTTPS - Protocol for communication between browsers and servers
  • HTML/CSS/JavaScript - Languages that structure and style web content
  • URLs - Unique addresses for every resource on the web

How It Works

When you type a URL into a browser: The browser sends an HTTP request to a web server → The server processes the request → The server returns HTML/CSS/JS files → The browser renders the page visually.
