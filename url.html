Uniform Resource Locator (URL)

A Uniform Resource Locator (URL) is the address used to access resources on the web, such as web pages, images, and files.

URL Structure

A complete URL has several parts:

https://www.example.com:443/path/to/page?query=123#section
  • Protocol - http:// or https:// (how to access the resource)
  • Domain Name - www.example.com (server location)
  • Port - :443 (optional, default ports are 80 for HTTP, 443 for HTTPS)
  • Path - /path/to/page (specific resource location on server)
  • Query String - ?query=123 (parameters sent to server)
  • Fragment - #section (anchor within the page)

URLs can only contain certain characters. Spaces become %20, and special characters are "percent-encoded" (e.g., # becomes %23).
