Web Servers

A web server is a computer system that hosts websites and delivers web content to users' browsers upon request using HTTP protocols.

Popular Web Server Software

  • Apache HTTP Server - Most widely used, open-source, highly configurable
  • Nginx - Known for high performance, low memory usage, and load balancing
  • Microsoft IIS - Windows-integrated server for .NET applications
  • Node.js - JavaScript runtime that can act as a web server

How Web Servers Work

  1. Browser sends HTTP request to server (e.g., GET /index.html)
  2. Server receives request and processes it
  3. Server locates requested file or runs server-side code
  4. Server sends HTTP response with status code and content
  5. Browser renders the response
