Domain Name System (DNS)

The Domain Name System (DNS) is the phonebook of the internet, translating human-readable domain names (google.com) into machine-readable IP addresses (142.250.190.46).

How DNS Works

  1. You type "example.com" into browser
  2. Browser checks local cache for IP address
  3. Query sent to Recursive Resolver (usually your ISP)
  4. Resolver asks Root Nameserver for .com TLD location
  5. TLD Nameserver directs to Authoritative Nameserver for example.com
  6. Authoritative Nameserver returns IP address
  7. Browser now can request website from that IP

💡 DNS was invented by Paul Mockapetris in 1983. Before DNS, everyone had to use a single HOSTS.txt file that was manually downloaded!
