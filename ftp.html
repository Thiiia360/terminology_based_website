File Transfer Protocol (FTP)

File Transfer Protocol (FTP) is a standard network protocol used to transfer files between a client and a server over the Internet or a local network.

FTP Features

  • Supports both anonymous and authenticated access
  • Uses separate control and data connections
  • Can transfer files in binary or ASCII mode
  • Supports resuming interrupted transfers
  • Can list directories and manage files on the server

FTP is less commonly used today for public file sharing due to security concerns, but it remains popular for internal file transfers and legacy systems. Secure alternatives include SFTP and FTPS.
