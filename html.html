Hypertext Markup Language (HTML)

Hypertext Markup Language (HTML) is the standard markup language for creating web pages. It defines the structure and content of web pages using elements like headings, paragraphs, links, and images.

HTML Versions

  • HTML 2.0 - 1995 (first standard)
  • HTML 4.01 - 1999 (widely used for a decade)
  • XHTML - 2000 (stricter XML-based version)
  • HTML5 - 2014 (current standard, adds video, audio, canvas)

HTML Features

  • Used to create the structure of web pages
  • Supports various media types including text, images, and videos
  • Can link to other web pages and resources
  • Is supported by all modern web browsers

HTML is the foundation of web development. While it defines the structure of a page, it is often combined with CSS for styling and JavaScript for interactivity.
