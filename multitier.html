Multitier Architecture (n-tier Architecture)

Multitier architecture (or n-tier architecture) is a client-server architecture that separates presentation, business logic, and data storage into independent layers.

The Three-Tier Architecture

  • Presentation Tier (Client Tier) - User interface (browser, mobile app). Handles user input and displays data.
  • Business Logic Tier (Application Tier) - Processes user requests, applies business rules, validates data. Often called the "middle tier."
  • Data Tier (Database Tier) - Stores and retrieves data from databases or file systems.

Most modern web applications use 3-tier or 4-tier architecture. Cloud computing has popularized "microservices" where the business tier is split into many small, independent services.
